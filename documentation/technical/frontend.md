# Frontend Technical Reference

## Layout

```
frontend/
├── src/
│   ├── main.tsx              entry point: creates the router and mounts it
│   ├── index.css             Tailwind import, fonts, tokens.css import, `dark` variant, Tailwind
│   │                         mapping of the tokens, shadcn variables, wrapper-level classes
│   ├── styles/tokens.css     palette (light, dark), type scale, wrapper spacing, rail and content widths
│   ├── routes/               file-based routes (TanStack Router)
│   │   ├── __root.tsx        root layout with the outlet; lazy-loads the dev tools in dev only
│   │   ├── index.tsx         placeholder home page
│   │   └── playground/       dev-only pages: index, goo, marble, motion
│   ├── routeTree.gen.ts      generated by the router plugin, never edited by hand
│   ├── components/
│   │   ├── ui/               shadcn components (Radix primitives)
│   │   ├── dev/              tweak-panel.tsx (Leva + Copy values), breakpoint-indicator.tsx
│   │   ├── goo/              goo-filter.tsx: `<GooFilter id>` SVG filter, `<Goo id>` wrapper
│   │   └── marble/           marble-background.tsx: still plus live marble canvas behind a zone
│   └── lib/
│       ├── utils.ts          `cn` class merging helper (clsx + tailwind-merge)
│       ├── tweaks/           model.ts (TweakSchema), use-tweaks.dev.ts, use-tweaks.prod.ts
│       ├── motion/           easings.ts (curves, springs, cssEasing, sampleSpring), tokens.ts
│       ├── goo/              tokens.ts (blur, alphaContrast, alphaOffset)
│       └── marble/           tokens.ts (values, pigments, GL limits), renderer.ts (WebGL1 marble)
├── public/brand/             logo.svg, logo-dark.svg
├── public/marble/            WebP stills of the marble, portrait and landscape, light and dark
├── components.json           shadcn config: style `radix-nova`, icon library `phosphor`
├── .oxlintrc.json            lint rules
├── tsconfig.app.json         `@/*` paths, plus `@/lib/tweaks/use-tweaks` mapped to the dev file for types
└── vite.config.ts            plugins, tweak hook alias, `@` alias to `src`, `/api` dev proxy
```

## Tweak workflow

- `useTweaks(folder, defaults, schema?)` is imported from `@/lib/tweaks/use-tweaks`. Vite resolves that exact path to `use-tweaks.dev.ts` under `vite` (serve) and to `use-tweaks.prod.ts` under `vite build`. The prod file returns `defaults` and does not import Leva.
- In dev, each call adds a Leva folder: numbers become sliders (`min`, `max`, `step` from the schema), `#hex` strings become colour pickers, other strings text fields, booleans toggles, strings with `options` selects. Nested groups become sub-folders.
- To save a value: move the slider until it looks right, press **Copy values** (bottom right) to copy every live folder as JSON, then paste the numbers into the matching `tokens.ts` defaults.
- `components/dev/tweak-panel.tsx` and `components/dev/breakpoint-indicator.tsx` are loaded with `React.lazy` behind `import.meta.env.DEV` in `routes/__root.tsx`, so the production build drops them. Check with `grep -ri "leva" frontend/dist` (no matches expected).
- `routes/playground/*` throw `notFound()` in `beforeLoad` when `!import.meta.env.DEV`. Their small route chunks are still emitted to `dist`.

## Design tokens

Values, bands, the app layout spec, motion and marble are in [design.md](design.md).

- Wrapper levels: `.section`, `.sub-section`, `.placement`, `.container` in `index.css` (components layer), spacing from `--section-padding`, `--section-gap`, `--sub-section-padding`, `--sub-section-gap`, `--placement-padding`, `--placement-gap`, `--container-padding`, `--container-gap` in `styles/tokens.css`. `.section` is capped at `--content-max`.
- Tailwind's own `container` utility is disabled with `@source not inline("container")` so the wrapper class stays fluid.
- Type scale (`@theme inline`, all `clamp()`): `text-display`, `text-heading`, `text-subheading`, `text-message-large`, `text-message`, `text-body`, `text-caption`, `text-mono`. Breakpoint `3xl` is 120rem.
- Motion tokens (`lib/motion/tokens.ts`): `fadeSlide`, `overshoot`, `bounceLand`, `springFollow`, `popScale`, `squash`, `stagger`, `pressFeedback`, `rippleReveal`, `letterStagger`, `nudge`, `iris`, `lightSweep`, `marbleDrift`, `shaderFadeIn`, `tabSpring`, `reducedFade`, plus `landingMotion` (not tweakable). Easing names come from `EASING_NAMES` in `lib/motion/easings.ts`; `cssEasing(name)` gives a `cubic-bezier()` or sampled `linear()` string for CSS and the Web Animations API.
- Marble (`lib/marble/tokens.ts`): `marbleDefaults` on the Marble folder, `MARBLE_PIGMENTS`, `MARBLE_GL`. Previewed at `/playground/marble`.
- Goo (`lib/goo/tokens.ts`): `blur` (feGaussianBlur stdDeviation), `alphaContrast` and `alphaOffset` (feColorMatrix alpha row).

## Commands

Run from `drop-app/`.

| Command                            | Does                                                                      |
| ---------------------------------- | ------------------------------------------------------------------------- |
| `pnpm dev:frontend`                | Vite dev server, forwards `/api` to `http://localhost:3000`               |
| `pnpm build`                       | `vite build` (generates the route tree), then `tsc -b`                    |
| `pnpm lint`                        | `oxlint`                                                                  |
| `pnpm format`, `pnpm format:check` | Prettier, config at `drop-app/.prettierrc.json` (4 spaces, double quotes) |

The build runs `vite build` before `tsc -b` because `routeTree.gen.ts` only exists after the router plugin has run.

## Conventions

- New shadcn components: `pnpm dlx shadcn@latest add <name>` from `frontend/`. Icons are Phosphor (`@phosphor-icons/react`); Lucide is not installed.
- Route files export `Route`; the `only-export-components` lint rule is off for `src/routes/**`.
