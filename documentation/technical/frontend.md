# Frontend Technical Reference

## Layout

```
frontend/
├── src/
│   ├── main.tsx              entry point: creates the router and mounts it
│   ├── index.css             Tailwind import, shadcn theme tokens, Geist font
│   ├── routes/               file-based routes (TanStack Router)
│   │   ├── __root.tsx        root layout with the outlet
│   │   └── index.tsx         placeholder home page
│   ├── routeTree.gen.ts      generated by the router plugin, never edited by hand
│   ├── components/ui/        shadcn components (Radix primitives)
│   └── lib/utils.ts          `cn` class merging helper
├── components.json           shadcn config: style `radix-nova`, icon library `phosphor`
├── .oxlintrc.json            lint rules
└── vite.config.ts            plugins, `@` alias to `src`, `/api` dev proxy
```

## Commands

Run from `drop-app/`.

| Command                            | Does                                                                      |
| ---------------------------------- | ------------------------------------------------------------------------- |
| `pnpm dev:frontend`                | Vite dev server, forwards `/api` to `http://localhost:3000`               |
| `pnpm build`                       | `vite build` (generates the route tree), then `tsc -b`                    |
| `pnpm lint`                        | `oxlint`                                                                  |
| `pnpm format`, `pnpm format:check` | Prettier, config at `drop-app/.prettierrc.json` (4 spaces, double quotes) |

The build runs `vite build` before `tsc -b` because `routeTree.gen.ts` only exists after the router plugin has run.

## Conventions

- New shadcn components: `pnpm dlx shadcn@latest add <name>` from `frontend/`. Icons are Phosphor (`@phosphor-icons/react`); Lucide is not installed.
- Route files export `Route`; the `only-export-components` lint rule is off for `src/routes/**`.
